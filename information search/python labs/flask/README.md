# Flask

Разработайте приложение аналогично заданию по Django. Вместо работы с панелью администрирования создайте ограничения на возможность выполнять операции Create и Update только зарегистрированным пользователям.

Приложение должно работать с базой данных (например MySQL) и предоставлять полный CRUD (создание, чтение, модификация, удаление) доступ к следующим сущностям:

- **Университет**
  - Полное название
  - Сокращенное название
  - Дата создания

- **Студент**
  - ФИО
  - Дата рождения
  - Университет (только из списка университетов, содержащихся в базе)
  - Год поступления

Доступ к операциям Create и Update должен быть разрешён только зарегистрированным пользователям. Операции чтения и удаления могут быть доступны в соответствии с логикой приложения.
