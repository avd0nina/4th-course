# Шифр Цезаря

[Шифр Цезаря](https://ru.wikipedia.org/wiki/%D0%A8%D0%B8%D1%84%D1%80_%D0%A6%D0%B5%D0%B7%D0%B0%D1%80%D1%8F) — это вид шифра подстановки, в котором каждый символ в открытом тексте заменяется символом, находящимся на некотором постоянном числе позиций левее или правее него в алфавите. Напишите программу, которая реализует шифрование Цезаря. Входные данные: путь до изначального файла с текстом, требуемый сдвиг и язык текста (на выбор английский либо русский). Результат работы — новый файл с зашифрованным текстом.
