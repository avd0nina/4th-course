# Django

Разработайте приложение, которое бы работало с базой данных (например MySQL) и предоставляло полный CRUD (создание, чтение, модификация, удаление) доступ к следующим сущностям:

- **Университет**
  - Полное название
  - Сокращенное название
  - Дата создания

- **Студент**
  - ФИО
  - Дата рождения
  - Университет (только из списка университетов, содержащихся в базе)
  - Год поступления

Доступ должен предоставляться как через панель администратора, так и через созданные вами страницы (по типу тех страниц, которые описаны в разделах [Формы](#forms) и [Модели](#models)).
