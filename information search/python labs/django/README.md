# Инструкция по запуску и проверке проекта


Проект реализует Django-приложение для работы с базой данных университетов и студентов.

Доступны две сущности:

### Университет

- полное название;
- сокращенное название;
- дата создания.

### Студент

- ФИО;
- дата рождения;
- университет;
- год поступления.

Для обеих сущностей реализованы операции CRUD:

- создание;
- просмотр;
- изменение;
- удаление.

Данные доступны через обычные страницы сайта и через административную панель Django.

## 2. Требования

Для запуска требуется:

- Python 3.9 или новее;
- доступ к терминалу;
- операционная система Windows, macOS или Linux.

Отдельно устанавливать MySQL для проверки не требуется: проект по умолчанию использует SQLite. База данных создается в файле `db.sqlite3`.

## 3. Запуск проекта

Откройте терминал и перейдите в папку проекта

### для macOS и Linux

Создайте виртуальное окружение, если папки `venv` еще нет:

```bash
python3 -m venv venv
```

Включите виртуальное окружение:

```bash
source venv/bin/activate
```

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

### для Windows

Создайте виртуальное окружение:

```powershell
py -m venv venv
```

Включите его:

```powershell
venv\Scripts\activate
```

Установите зависимости:

```powershell
python -m pip install -r requirements.txt
```

## 4. Создание базы данных

Выполните:

```bash
python manage.py migrate
```

После этой команды будет создан файл:

```text
db.sqlite3
```

## 5. Создание учетной записи администратора

Для входа в админ-панель выполните:

```bash
python manage.py createsuperuser
```

Далее укажите логин, электронную почту и пароль.

## 6. Запуск сервера

Выполните:

```bash
python manage.py runserver
```

После запуска открыть в браузере:

```text
http://127.0.0.1:8000/
```

Административная панель находится по адресу:

```text
http://127.0.0.1:8000/admin/
```

## 7. Проверка обычных страниц сайта

### Проверка университетов

Открыть:

```text
http://127.0.0.1:8000/universities/
```

Проверить:

1. создать университет;
2. открыть его подробную страницу;
3. изменить его данные;
4. удалить университет.

Пример записи:

```text
Полное название: Новосибирский государственный университет
Сокращенное название: НГУ
Дата создания: 1959-01-01
```

### Проверка студентов

Открыть:

```text
http://127.0.0.1:8000/students/
```

Проверить:

1. создать студента;
2. выбрать для него университет из выпадающего списка;
3. открыть подробную страницу;
4. изменить данные;
5. удалить студента.

Пример записи:

```text
ФИО: Иванов Иван Иванович
Дата рождения: 2002-05-10
Университет: НГУ
Год поступления: 2020
```

## 8. Проверка админ-панели

Открыть:

```text
http://127.0.0.1:8000/admin/
```

Войти под учетной записью суперпользователя.

В панели должны быть разделы:

- «Университеты»;
- «Студенты».

В каждом разделе можно:

- добавить запись;
- изменить запись;
- удалить запись;
- найти запись через поиск;
- использовать фильтры.

Записи, созданные на обычных страницах сайта, должны отображаться в админ-панели, потому что обе части приложения используют одну базу `db.sqlite3`.

## 9. Проверка автоматических тестов

В папке проекта выполнить:

```bash
python manage.py test catalog
```

Ожидаемый результат:

```text
Ran 3 tests
OK
```

Тесты проверяют CRUD университетов и студентов, связь студента с университетом и обязательность выбора университета.
