# Лабораторная работа № 2
## Экспериментальные методы исследования уязвимостей (сканер ScanOVAL)

---

## 1. Цель работы

Приобретение навыков выявления, оценки критичности и устранения уязвимостей в рабочей ИТ-среде с использованием бесплатного сканера ScanOVAL от ФСТЭК России.

---

## 2. Объект исследования

Основной объект — виртуальная машина Metasploitable 2, развёрнутая в VirtualBox. Это учебный дистрибутив Linux с намеренно оставленными уязвимостями (устаревшие версии Apache, MySQL, Samba, PHP и др.).

Допускается вместо Metasploitable использовать:

- виртуальную машину с Windows 7 или Windows XP без обновлений безопасности;
- виртуальную машину с Astra Linux 1.7 SE без установленных обновлений;
- собственную рабочую ОС (результат может быть малоинформативным).

**Нельзя сканировать чужие компьютеры и серверы без письменного разрешения владельца.**

### 2.1 Установка Metasploitable 2

Инструкция по развёртыванию в VirtualBox:  
https://spy-soft.net/install-metasploitable-virtual-box/

---

## 3. Краткие сведения о ScanOVAL

ScanOVAL — бесплатная программа ФСТЭК России для автоматизированного обнаружения уязвимостей программного обеспечения на локальном компьютере. Работает на основе OVAL-описаний (Open Vulnerability and Assessment Language, спецификация не ниже 5.10.1), которые скачиваются с сайта БДУ ФСТЭК.

Официальный сайт:  
- Windows: https://bdu.fstec.ru/scanoval  
- Linux: https://bdu.fstec.ru/scanovalforlinux

**Важно:** ScanOVAL — хостовый сканер. Он проверяет только тот компьютер, на котором установлен. Сетевое сканирование (по IP-адресам) не поддерживается. Поэтому ScanOVAL нужно установить внутрь сканируемой виртуальной машины.

---

## 4. Порядок выполнения работы

### 4.1 Шаг 1. Подготовка виртуальной машины

1. Установить VirtualBox на свой компьютер.
2. Развернуть виртуальную машину Metasploitable 2 (или иную выбранную ОС) по инструкции выше.
3. Запустить виртуальную машину и войти в неё.
4. Убедиться, что в ВМ есть доступ в интернет (нужен для скачивания дистрибутива ScanOVAL и OVAL-описаний).

### 4.2 Шаг 2. Установка ScanOVAL внутри виртуальной машины

#### 4.2.1 Windows

1. Внутри ВМ открыть браузер и перейти на https://bdu.fstec.ru/scanoval.
2. Скачать дистрибутив `ScanOVAL.msi` и XML-файл с OVAL-описаниями.
3. Запустить `ScanOVAL.msi`, принять лицензию, установить со стандартными настройками.
4. Требование: Microsoft .NET Framework 4.8 или выше.

#### 4.2.2 Linux (Astra Linux 1.7 SE, Альт, Роса)

1. Внутри ВМ перейти на https://bdu.fstec.ru/scanovalforlinux.
2. Скачать архив установщика и deb-пакет с OVAL-контентом.
3. Распаковать архив:  
   `sudo tar -C /var/lib -xvf <scanovalrepo>.tar.gz`
4. Установить ключ:  
   `sudo apt-key add /var/lib/scanoval/repo/PUBLIC-GPG-KEY-scanoval`
5. Создать файл репозитория:  
   `echo "deb file:///var/lib/scanoval/repo 1.7_x86-64 main content" | sudo tee -a /etc/apt/sources.list.d/scanoval.list`
6. Обновить пакеты:  
   `sudo apt update`
7. Установить:  
   `sudo apt-get install openscap-scanner openscap-common openssl scanoval`
8. Установить OVAL-контент:  
   `sudo dpkg -i <scanovalcontent>.deb`

### 4.3 Шаг 3. Запуск сканирования

1. Запустить ScanOVAL внутри виртуальной машины.
   - Windows: ярлык на рабочем столе или из меню «Пуск».
   - Linux: `sudo /usr/bin/scanoval`.

2. Загрузить OVAL-описания.  
   В главном окне нажать кнопку «Открыть файл», выбрать скачанный XML-файл с OVAL-описаниями и нажать «Открыть».  
   По умолчанию на Linux файл находится в папке `/var/lib/scanoval/data`.

   **Важно:** при загрузке проверяется цифровая подпись файла. Если подпись недействительна, содержимое игнорируется.

3. Запустить аудит.  
   Нажать кнопку «Выполнить аудит». Дождаться завершения (сообщение «Выполнение...» исчезнет).

4. Просмотреть результаты.  
   В главном окне для каждой проверки отобразится «обнаружено» или «не обнаружено» с указанием уровня опасности.

5. Сохранить отчёт.  
   Доступно сохранение в формате HTML или CSV.

### 4.4 Шаг 4. Анализ результатов

1. Выбрать 3–5 обнаруженных уязвимостей.
2. Найти их идентификаторы в отчёте и открыть описания на сайте БДУ ФСТЭК.
3. Оценить критичность по CVSS 3.1 (документация и калькулятор: https://www.first.org/cvss/).
4. Сформулировать рекомендации:
   - уязвимости низкой критичности могут быть приняты;
   - для средних и высоких — предложить меры устранения или компенсирующие меры (обнаружение, реагирование, резервирование).

---

## 5. Форма отчётности

Отчёт объёмом не более 3 страниц. Включить:

- скриншоты ScanOVAL с загруженными OVAL-описаниями и результатами аудита;
- таблицу с 3–5 уязвимостями (идентификатор, описание, CVSS, рекомендация);
- вывод.
