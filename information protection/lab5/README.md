## 2. Теоретическая справка

### 2.1. Метод LSB

Метод наименьшего значащего бита (Least Significant Bit, LSB) заключается в замене младших битов пикселей изображения битами сообщения. Изменение младшего бита меняет значение цвета на 1 из 255, поэтому визуально незаметно. Для 24-битного BMP каждый пиксель содержит три байта (R, G, B); ёмкость контейнера составляет примерно ширина × высота × 3/8 байт.

### 2.2. Стегоанализ

Стегоанализ — обнаружение факта сокрытия информации в контейнере. Основные методы: визуальный анализ младших битовых плоскостей, статистические тесты (хи-квадрат, RS-анализ), сигнатурный поиск известных форматов.

### 4.2. Задание 2. Внедрение сообщения сторонним ПО

Используя Steghide (или SilentEye), внедрите текстовое сообщение в изображение.

Порядок для Steghide:

1. Подготовьте файл secret.txt с вашими ФИО.
2. Выполните внедрение:

steghide embed -cf cover.jpg -ef secret.txt -sf stego.jpg

3. Проверьте контейнер:

steghide info stego.jpg

4. Извлеките сообщение:

steghide extract -sf stego.jpg -xf recovered.txt

5. Сравните хэш-суммы:

sha256sum secret.txt recovered.txt

Порядок для SilentEye: запустите программу, выберите режим «Скрыть», загрузите контейнер и файл сообщения, задайте пароль (опционально), выполните внедрение. Затем проверьте извлечение в режиме «Извлечь».

Задание к отчёту: скриншоты внедрения и извлечения, сравнение хэш-сумм. Файл назовите Фамилия_ИО_2_1.
