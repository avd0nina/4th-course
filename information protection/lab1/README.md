# Лабораторная работа № 1
## «Аналитическое исследование угроз и уязвимостей ИТ-безопасности»

---

## 1.1. Аналитическая часть

**Цель работы** — составить и аргументировать свою версию «ТОР-5» актуальных угроз ИТ-безопасности при использовании ИКТ.

### Краткие рекомендации по выполнению

Поскольку угрозы могут сильно различаться в разных ситуациях, то рекомендуется конкретизировать объект исследования, выбрав то, что лучше соотносится с личным опытом применения ИКТ, конкретизировав тему соответствующим образом.

Примеры конкретизированных тем (естественно, что данный список не является исчерпывающим, он может дополняться темами по инициативе студентов):

- «ТОР-5» актуальных угроз для пользователя домашнего компьютера
- «ТОР-5» актуальных угроз для пользователя смартфона
- «ТОР-5» актуальных угроз в системах онлайн-образования
- «ТОР-5» актуальных угроз, обусловленных вредоносными программами
- «ТОР-5» актуальных угроз для корпоративной информационной системы
- «ТОР-5» актуальных угроз для пользователя при работе в социальных сетях
- «ТОР-5» актуальных угроз для пользователей интернет-банков и мобильных банковских приложений
- «ТОР-5» актуальных угроз для IoT-устройств (на примере «умных» часов, колонок и т. п.)
- «ТОР-5» актуальных угроз в системах «умный дом»
- «ТОР-5» актуальных угроз при разработке программного обеспечения "open source"

### Краткие рекомендации по выполнению

**Источники информации.** Для ознакомления с угрозами и уязвимостями используются:

- официальные каталоги угроз и уязвимостей, поддерживаемые отечественными и международными организациями (ссылки на основные такие источники даны в лекциях);
- материалы об угрозах, уязвимостях и событиях безопасности, опубликованные на специализированных интернет-ресурсах — поддерживаются профессиональными сообществами, производителями средств анализа защищённости, мониторинга безопасности, антивирусной защиты, обнаружения вторжений и др. (ссылки на ряд известных ресурсов даны в конце задания);
- личный опыт студента в области ИТ-безопасности.

Примеры возможных источников информации для подготовки работы приведены в конце данного файла.

### Порядок выполнения задания

Задание можно выполнять в классе во время практики, консультируясь с преподавателем в очном режиме при возникновении затруднений.

Можно выполнять самостоятельно дома, в этом случае при необходимости вопросы задавать через ГУГЛ-класс.

**Внимание!** При выполнении этого задания часто допускаются ошибки, связанные с тем, что путаются понятия «угроза» и «уязвимость».

**Уязвимость** — это свойство системы, которое позволяет реализовать угрозу (образно говоря, «дырка в заборе»).

**Угроза** — это совокупность условий и факторов, в результате которых может быть осуществлено воздействие на информацию (информационные ресурсы), приводящее к негативным последствиям для её обладателей и пользователей.

С использованием одной и той же уязвимости могут быть реализованы разные угрозы. Угроза — это вектор, характеризующийся пятью параметрами, уязвимость является только одним из них. При характеристике угроз надо описать:

- **источник** (кто/что является исполнителем угрозы — субъективные или объективные факторы, для субъективных источников (люди) сделать обоснованные предположения о возможных целях и мотивах при реализации рассматриваемой угрозы);
- **как может быть реализована угроза** (здесь надо указать, через какие уязвимости и каким способом можно реализовать угрозу);
- **на какие объекты направлена угроза и каковы будут её возможные последствия** (например, кража клиентских данных с сервера — утечка аутентификационных данных с возможным последующим финансовым ущербом для клиентов, или нарушение доступности сервиса электронного голосования и репутационный ущерб и т. п.).

## Форма отчётности

Текстовый документ (тезисы) в электронном виде объёмом до 3 стр. в формате PDF.

В начале файла должны быть указаны ФИО автора, группа, наименование задания, дата оформления отчёта.

На все источники, материалы которых студент использует для аргументирования своих выводов, должны быть точные ссылки с указанием полной информации об источнике в виде подстрочных сносок или в форме списка источников в конце текста.

Выводы, сделанные по принципу «я так думаю» без ссылки на аргументы, приведённые в опубликованных источниках и/или подкреплённые конкретными примерами (из личного опыта или опыта друзей-родственников-знакомых), не считаются обоснованными.

Приоритет оформления — таблица с колонками: «угроза» — «обоснование выбора» — «приоритетные решения по устранению угрозы» — «ссылка на источник, если она есть».

## Оценивание

При оценивании учитываются:

- соответствие заданию и полнота ответа, корректное использование основных понятий, аргументированность выводов;
- использование адекватных и заслуживающих доверия источников (учебных и научных изданий, профессиональных ресурсов интернет), корректные ссылки на них по тексту ответа;
- соблюдение установленного срока.
